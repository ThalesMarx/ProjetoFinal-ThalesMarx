# e-Wallet API (Carteira Digital)

Projeto Spring Boot em 3 camadas (`Repository`, `Service`, `Controller`) com suíte completa de testes automatizados (Unitários com JUnit 5 + Mockito, Integração com MockMvc, Interface E2E com Selenium WebDriver) e verificação de cobertura mínima de 80% com JaCoCo.

## Como executar os testes e validar cobertura

```bash
mvn clean verify
```

O relatório detalhado do JaCoCo será gerado em `target/site/jacoco/index.html`.
